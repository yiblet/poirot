# SERIESSUM contract

`SERIESSUM(x,n,m,coefficients)` evaluates each term `coefficient[i] * x^(n+i*m)` in row-major coefficient order. Both builtin policies select this one contract. The [Microsoft definition](https://support.microsoft.com/en-us/excel/functions/seriessum-function) establishes the series and nonnumeric VALUE error. More detailed admission and term behavior follows pinned [ClosedXML MathTrigTests.cs:1981–2045](https://github.com/ClosedXML/ClosedXML/blob/09f2f21a60e821ce7fb18ca3576b272e5dd6d921/ClosedXML.Tests/Excel/CalcEngine/MathTrigTests.cs#L1981), `SignatureAdapter.cs:653–690` and `MathTrig.cs:895–912` at the same revision. `AnyValue.cs:226–254` establishes that single-cell references are scalar coefficients while 1×1 arrays remain collections.

Scalar x, n, m and scalar coefficients (including single-cell references) accept numbers, blanks as zero, and contextual numeric text; logicals, empty text and omitted arguments return VALUE. Numeric text retains the evaluator's metered locale/date parser. Arrays, including 1×1 arrays, and multi-cell coefficient collections accept numbers and blanks as zero; text and logicals return VALUE. Every blank retains its exponent index. References read only the selected x/n/m scalar; coefficient references traverse all positions, sheet-first then row-major.

Each coefficient is admitted immediately before evaluating its term, matching the source loop. Earlier argument errors win; an earlier invalid term wins over a later coefficient error. The kernel computes each exponent directly, avoiding Horner transforms and multiplicative power recurrence assumptions. Zero to zero is one for this consumer. Zero to a negative exponent, nonreal powers, nonfinite terms and overflowing intermediate sums return NUM, even with a zero coefficient. Overflow cannot be repaired by later cancellation. This is not the scalar POWER error contract.

Length/capacity and traversal work are admitted before reference traversal; each scalar and contextual text conversion retains normal accounting. Operational failures escape IFERROR. New registration invalidates raw evaluator snapshots (version 27) and artifact compatibility identity (revision 28).

Independent Calc 26.2.6.3 observations are retained in `crates/poirot-test-runner/evidence/seriessum-libreoffice.json`. Calc differs: it accepts logicals, skips collection text while retaining positions, reports VALUE for several invalid powers, returns VALUE for zero base and zero initial exponent, and shortcuts many other zero-base series to zero. These disagreements do not establish Excel semantics. Native Excel was unavailable; the explicit contract above uses the documented definition and pinned source, with no claim of complete Excel parity.
